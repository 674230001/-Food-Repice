NOIRÉ Product Studio
ระบบจัดการคลังสินค้าและสินค้า พัฒนาด้วย PHP OOP, MySQL และ CSS ในธีมสีดำ-ครีม ดีไซน์เรียบหรูและรองรับการใช้งานบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
ภาพรวมโปรเจกต์
NOIRÉ Product Studio เป็นเว็บแอปพลิเคชันสำหรับจัดการรายการสินค้าในคลัง เหมาะสำหรับใช้ศึกษา PHP แบบ Object-Oriented Programming (OOP) และการเชื่อมต่อฐานข้อมูล MySQL
ฟีเจอร์หลัก
- Create: เพิ่มสินค้าใหม่
- Read: แสดงรายการสินค้าและข้อมูลสรุป
- Update: แก้ไขข้อมูลสินค้า
- Delete: ลบสินค้า พร้อมกล่องยืนยันก่อนลบ
- ค้นหาสินค้าจากชื่อหรือหมวดหมู่
- สรุปจำนวนรายการสินค้าและมูลค่ารวมของสินค้าในคลัง
- แสดงสถานะสินค้า: พร้อมขาย, ใกล้หมด และหมดสินค้า
- Responsive UI ธีมสีดำ-ครีม
- ใช้ PDO และ Prepared Statements ในการจัดการฐานข้อมูล
- มี CSRF token สำหรับตรวจสอบคำขอจากแบบฟอร์ม
เทคโนโลยีที่ใช้
- PHP 8.x (แนะนำ)
- MySQL / MariaDB
- HTML5
- CSS3
- XAMPP
- PHP PDO

วิธีติดตั้งบน XAMPP
1. ดาวน์โหลดโปรเจกต์
ดาวน์โหลด ZIP ของโปรเจกต์และแตกไฟล์ จากนั้นคัดลอกโฟลเดอร์ sk031_black_cream ไปไว้ใน:
C:\xampp\htdocs\sk031_black_cream
2. เปิดบริการ XAMPP
เปิด XAMPP Control Panel แล้วกด Start ที่ Apache และ MySQL
3. สร้างฐานข้อมูล
1. เปิด http://localhost/phpmyadmin
2. เลือกแท็บ Import
3. เลือกไฟล์ database.sql ภายในโฟลเดอร์โปรเจกต์
4. กด Import หรือ Go เพื่อเริ่มนำเข้าข้อมูล
สคริปต์จะสร้างฐานข้อมูลชื่อ noire_inventory พร้อมตาราง products และข้อมูลตัวอย่าง
4. ตรวจสอบการเชื่อมต่อฐานข้อมูล
เปิดไฟล์ app/Database.php และตรวจสอบค่าการเชื่อมต่อ:
private string $host = 'localhost';
private string $dbName = 'noire_inventory';
private string $username = 'root';
private string $password = '';
ค่าข้างต้นเป็นค่าทั่วไปของ XAMPP หาก MySQL ของคุณมีรหัสผ่าน ให้แก้ $password ให้ตรงกับเครื่องของคุณ
5. เปิดเว็บไซต์
เข้า URL:

http://localhost/sk031_black_cream/
วิธีใช้งาน
1. กด เพิ่มสินค้า เพื่อเพิ่มรายการใหม่
2. กรอกชื่อสินค้า หมวดหมู่ ราคา จำนวนคงเหลือ และรายละเอียด
3. กดบันทึกเพื่อจัดเก็บข้อมูลลง MySQL
4. ใช้ช่องค้นหาเพื่อค้นหาจากชื่อหรือหมวดหมู่
5. กด แก้ไข เพื่อเปลี่ยนข้อมูล หรือ ลบ เพื่อลบรายการหลังยืนยัน
การแก้ปัญหาเบื้องต้น
- เปิดเว็บไม่ได้: ตรวจสอบว่า Apache ทำงานอยู่ และโฟลเดอร์อยู่ใน C:\xampp\htdocs\
- เชื่อมต่อฐานข้อมูลไม่ได้: ตรวจสอบว่า MySQL ทำงานอยู่ และค่าฐานข้อมูลใน app/Database.php ถูกต้อง
- ไม่พบฐานข้อมูล: นำเข้า database.sql ผ่าน phpMyAdmin อีกครั้ง
- พบข้อผิดพลาดเกี่ยวกับ mb_substr(): เปิดใช้งาน PHP extension mbstring ใน php.ini แล้ว Restart Apache
หมายเหตุ
โปรเจกต์นี้เป็นตัวอย่างเพื่อการศึกษา PHP OOP และ CRUD สร้างขึ้นใหม่โดยใช้แนวทางโปรเจกต์อ้างอิง ไม่ใช่สำเนาโค้ดจาก repository ต้นฉบับ หากนำไปใช้จริงควรเพิ่มระบบเข้าสู่ระบบ การกำหนดสิทธิ์ผู้ใช้ และการตั้งค่าความปลอดภัยสำหรับสภาพแวดล้อม production
